# Slingshot Challenge

A 2D browser-based game where you use a slingshot to launch a ball over walls and hit targets!

## How to Play

1. Open `index.html` in your web browser
2. Adjust the angle and power sliders to set your shot
3. Click "Launch!" to fire the ball
4. Navigate the ball through gaps in the wall to hit the target
5. Complete levels to progress - walls get more challenging!

## Game Features

- **Slingshot Mechanics**: Control both angle (10-80°) and power (10-100%)
- **Physics-Based Movement**: Realistic gravity and trajectory
- **Progressive Difficulty**: Each level introduces more complex wall configurations with smaller gaps
- **Score System**: Earn points based on level completion
- **Visual Feedback**: Clear indicators for success and failure

## Controls

- **Angle Slider**: Adjust launch angle
- **Power Slider**: Set launch power
- **Launch Button**: Fire the ball
- **Reset Level Button**: Restart current level

## Level Progression

- Level 1: Single large gap - Learn the basics
- Level 2: Gap positioned higher - Adjust your aim
- Level 3: Two gaps - Choose your path
- Level 4+: Increasingly difficult configurations with smaller gaps

## Technology

Built with vanilla HTML5, CSS3, and JavaScript using Canvas API for rendering.
